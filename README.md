## 🌟 Key Features

- **🔍 Smart Home Dish Search:** Type any dish name (e.g. *"Paneer Tikka"*, *"Butter Chicken"*, *"Pasta Carbonara"*) to instantly generate natural, delicious recipes with realistic cook times and instructions.
- **🥘 Interactive Ingredient Engine:** Add ingredients from your fridge/pantry to craft bespoke recipes tailored to whatever you have on hand.
- **🎨 Dynamic AI Food Photography:** Every generation synthesizes dedicated, mouth-watering culinary imagery matching the exact dish presentation.
- **📖 Persistent Cookbook:** 1-tap save with full offline `localStorage` and `RecipeRepository` caching, category filters (*✦ AI Generated, Indian Food, Chef's Favorites, Desserts*), and quick unsave.
- **📱 Dual Web & Flutter Cross-Platform UI:** Glassmorphic modern dark-mode interface with frosted blur, micro-animations, and responsive mobile layouts.

## 💻 Getting Started

### 1. Web Application
Simply open `index.html` in any modern web browser or serve with Python:
```bash
python -m http.server 3000 --directory site/public
```
Navigate to: `http://localhost:3000`

### 2. Flutter Mobile / Web App
```bash
cd flutter_app
flutter pub get
flutter run -d chrome # or run on connected Android/iOS device
```
